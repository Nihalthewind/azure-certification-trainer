# QuestionNavigator

Pattern de navigation directe dans la banque ou une session d’examen, avec recherche, états et repère de question courante.

Dans les thèmes du parcours, les vignettes affichent uniquement le numéro et l’ID. Les couleurs success/error indiquent le résultat ; le label accessible et l’infobulle conservent l’état détaillé. Favoris et signalements restent présents. Aucun résultat enregistré n’est modifié.
