# WorkspaceToolbar

Pattern de contrôle d'une session de questions.

Responsabilités :

- recherche et filtre de domaine ;
- accès au navigateur de questions ;
- entrée/sortie du mode Focus ;
- contrôles contextuels d'examen.

Le mode Focus est un **état du shell de travail** : il doit être accessible en un clic depuis la session, et la sortie doit toujours rester visible.
