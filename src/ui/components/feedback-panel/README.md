# FeedbackPanel

Présente le résultat et l'explication après validation d'une question.

États :
- `success` : réponse correcte ;
- `error` : réponse incorrecte ;
- `reference` : correction à comparer lors d'une auto-évaluation.

Le composant ne porte pas le concept « À revoir » : celui-ci reste une action utilisateur distincte du résultat de correction.
