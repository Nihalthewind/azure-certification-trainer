# Product Vision

Apprendre → pratiquer → comprendre ses erreurs → réviser → se tester.

## Utilisateur / valeur

Technicien ou administrateur préparant AZ-104 : banque structurée, corrections, sessions ciblées et progression claire. AZ-305/imports utilisent le même moteur.

## Actuel — V3 Product Experience

Introduction → Accueil (formation/modules) → Entraînement → correction → Révisions → Examen blanc. Paramètres secondaire unique. Anciens liens Parcours compatibles avec Accueil.

DomainSelector utilise le catalogue actif. Révisions regroupe erreurs, favoris et marques à revoir mémorisées. Couverture = questions explorées, pas une note ou garantie de réussite. Modules accessibles sans verrouillage artificiel.

AZ-104 : 568 questions, cinq domaines, examen 48 questions/100 minutes. Progression, notes, favoris et historique locaux ; transfert par export/import. PWA facultative quand disponible, accès navigateur permanent.

## Principes UX

Formation avant statistiques ; une action dominante ; question/correction prioritaires ; feedback clair et progression discrète ; navigation prévisible, clavier/focus ; mobile adapté et thèmes cohérents ; aucun contrôle fictif.

## Limites / vision

Aucun compte cloud, API, abonnement ou sync distante. Profil local ; traduction externe dépendante du réseau. Voir [roadmap](roadmap.md) et [décisions](decisions/README.md).
